Open with two or three sentences that define the reader's problem and explain what this guide will help them decide or understand.

## First main section

Explain the core idea in plain English. Define technical terms before using them repeatedly.

### Supporting point

Use short paragraphs, concrete examples, and tables where they genuinely make a comparison easier.

## Selection or application considerations

- State the factor to check.
- Explain why it matters.
- Note any condition that changes the recommendation.

## Common mistakes

Call out assumptions that can lead to a poor selection, unreliable operation, or an unsafe design.

## Key takeaway

Summarize the practical decision in a short paragraph. Link to another guide when a reader needs the next step.

## Sources and references

- List primary standards, manufacturer documentation, datasheets, or test definitions used to verify the guide.
- Link to the exact source page where possible and state the document revision or access date when it matters.
